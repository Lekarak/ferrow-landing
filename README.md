# Ferrow – AI Feedback Analysis Landing Page

A landing page for **Ferrow**, a fictional AI startup that turns customer feedback into product decisions. Built as a portfolio project.

## Features

- Responsive design from mobile to desktop
- Product mockup built entirely with HTML and Tailwind, no images
- Monthly/yearly pricing toggle
- Accessible FAQ accordion built on native `<details>`
- Self-hosted fonts (Inter and Instrument Serif) for fast loading
- Statically rendered for instant page loads

## Tech stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Vercel

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
